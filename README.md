# SnapExpand
SnapExpand — Text Expander &amp; Snippet Hotkeys

Type a short trigger and instantly expand it into full text in any input box. Assign hotkeys to insert snippets, and manage everything from one settings page with export/import.

Similar To Macro Expansion.

What's inside:

Trigger expansion — type dt → "date and time", etc. 
Works in plain inputs, textareas, and contenteditable (Gmail-style editors), across all frames on any site.

Smart matching — by default, expansion fires right after you type a space/punctuation following the trigger, not the instant the trigger completes. I chose this over "immediate" mode because your own example (ph → "phone number") would otherwise fire the moment you type ph while trying to type "phone" yourself. Immediate mode is there too if you want it — for that mode I'd recommend distinctive triggers like ;ph.

Per-snippet hotkeys — click "Set hotkey" on any snippet, press the combo (e.g. F4), done. Backspace clears it, Esc cancels. Insertion happens at the cursor regardless of any trigger.

Right-click menu — optional per snippet, toggled in each row's "⋯" advanced panel.
Export/import — full JSON backup, with a choice to replace or merge on import.

Cursor placeholder — put {|} in a replacement to land the cursor mid-text (e.g. Dear {|},).
Optional clipboard copy — global default or per-snippet override.
